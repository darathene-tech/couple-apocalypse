Make a FINAL visual/UI polish pass on the existing Couple Apocalypse game.

IMPORTANT:
This is NOT a feature update.
Do NOT add new gameplay, mechanics, systems, screens, functionality, or content.

The game already has everything it needs.

The goal of this update is ONLY to make the existing game feel more like a fun, polished, shareable mobile game and less like a technical/developer dashboard.

Do not rebuild the game.
Do not remove existing functionality.
Do not change the game mechanics.

## 1. FIX THE TITLE SPACING AND HIERARCHY

The “COUPLE APOCALYPSE” title currently sits too close to the top of the screen and feels cramped.

Give the title significantly more breathing room above it.

Create a clear visual hierarchy:

FIELD REPORT // 01
        ↓
comfortable vertical spacing
        ↓
COUPLE APOCALYPSE 💔
        ↓
comfortable spacing
        ↓
subtitle / game introduction
        ↓
game content

The title should feel like the main hero element of the screen, not something squeezed between the top navigation and the rest of the UI.

Keep the chunky display font and existing visual identity, but give the title enough surrounding space that it feels intentional and balanced on mobile.

Make sure the title does not feel crowded against the browser/top edge or the elements above it.

## 2. MAKE THE GAME FEEL LIKE A GAME, NOT A DEVELOPER DASHBOARD

The current visual language is too technical and structured.

Keep the existing dark aesthetic, but make the experience feel more like:

- A fun arcade game
- Gen-Z internet humour
- Slightly chaotic
- Playful
- Shareable
- Visually expressive

Rather than:

- A developer dashboard
- A sci-fi control panel
- A technical simulation interface
- A portfolio/demo project

Do NOT completely throw away the current aesthetic.

Keep:
- Dark background
- Pink/purple/blue accent colours
- Chunky Couple Apocalypse title
- Cute character style
- Couple obstacles
- Field-report concept
- Existing typography where it works
- Existing overall visual identity

But soften the overly technical presentation.

## 3. REDUCE VISUAL CLUTTER

There are currently too many small technical labels, thin borders, status indicators and uppercase UI elements competing for attention.

Simplify the visual hierarchy.

Reduce the visual prominence of:
- Tiny technical labels
- Excessive uppercase text
- Unnecessary technical-looking borders
- Overly dense status information
- Elements that make the interface feel like a dashboard

Do not delete information that is required for gameplay.

Instead, make secondary information visually quieter so the main game elements stand out.

## 4. MAKE THE START SCREEN FEEL MORE PLAYFUL

The start screen should immediately communicate:

“This is a ridiculous game. Pick your character, pick your vibe, and survive.”

Give the main game introduction more breathing room and personality.

The visual hierarchy should feel closer to:

💔

COUPLE APOCALYPSE

“The world is full of couples. Stay single.”

CHOOSE YOUR SURVIVOR

[character choices]

CHOOSE YOUR VIBE

[theme choices]

STAY SINGLE →

Do not literally force this exact layout if it conflicts with the existing responsive design, but use this as the visual hierarchy and feeling.

The start screen should feel inviting and playful rather than like a settings/configuration screen.

## 5. MAKE CHARACTER SELECTION MORE VISUAL

The existing character choices feel too small and UI-like.

Make the three existing character options more visually prominent.

The player should be able to immediately see the difference between:

- Feminine
- Masculine
- Neutral

Make the character previews larger and more expressive while keeping the same cute, simple character style.

Do not create a complex character creator.

Do not add additional character types.

This is only a visual improvement to the existing three choices.

Keep the existing five themes and their names exactly as they are:

- Single & Stable
- Emotionally Unavailable

Keep their existing colour directions:

Single & Stable:

Keep the existing:

“STAY SINGLE →”

button.

- Strong visual hierarchy

- Clear tap target on mobile

## 8. CREATE MORE VISUAL BREATHING ROOM
